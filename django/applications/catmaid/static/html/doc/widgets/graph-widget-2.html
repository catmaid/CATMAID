Graph Widget 2 shows neurons and their connections as a graph. A graph node is a neuron, a part of a split neuron or a group of neurons and parts. Edges are built from the links of individual treenodes to connectors, with one edge per link type and pair of graph nodes. All link types can be shown, e.g. synapses and gap junctions. The link types to use are selected in the Edges tab.

Tabs

  • Main: append and remove neurons from another widget, clear and refresh the graph, clone the widget, save the graph to a file and open saved graphs.
  • View: fit and zoom the view, mouse wheel sensitivity, and how node labels, nodes and edges look (edge labels, label text, edge width).
  • Groups: group the selected nodes into one node, ungroup, and group neurons with the same name or the same color.
  • Grow: add the partners of the selected nodes over a number of orders (Circles), or the neurons on paths between picked sources and targets (Paths). Both follow the link types selected in the Edges tab. Selected parts of split neurons only grow along their own links.
  • Nodes: layouts, node colors (e.g. review status, betweenness centrality, circles of hell) and unconnected nodes.
  • Edges: edge colors, link types and their colors, arrow shapes and filters for edges, see below.
  • Selection: annotate, measure edge risk, hide, lock and remove the selected nodes, select by name and invert the selection.
  • Selections: remember named sets of nodes, arrange them as columns and fade or hide edges between them.
  • Subgraphs: split the selected neurons into axon and dendrite, into axon, backbone dendrite and dendritic terminals, by synapse clusters, at a tag or at the active node, or reset the splits. Splits are kept when the graph is refreshed.
  • Align: align and distribute the selected nodes and snap nodes to a grid.
  • Export: GML, SVG and adjacency matrix files, the Connectivity Matrix widget, a plot of the graph and graph statistics.

Filtering edges

The Edges tab has the same filters as the old Graph Widget, with other names:

  • Min. links hides edges with fewer links (old: "Hide edges with less than n synapses"). It applies to all link types.
  • Min. confidence ignores links whose confidence, or whose partner link's confidence, is lower (old: "Filter synapses below confidence").
  • Synapse type with Hide and Show hides or shows synaptic edges between axon and dendrite parts, e.g. axo-dendritic edges (old: "Hide/Show").

Edges removed by these filters aren't counted as hidden: Show hidden in the Selection tab only shows elements hidden by hand.

Node filters

Like in many widgets, node filters are available through the funnel icon in the title bar. If filters are active and Apply node/edge filters is checked in the Edges tab, a connector only counts if at least one of the treenodes linked to it is allowed by the filters. Splitting and grouping work with node filters as well.

Saving and opening graphs

Save stores the graph as JSON file: the neurons with their splits, groups, node positions, hidden and locked nodes, selections and the settings of all tabs. Connections aren't stored, they are loaded again when the file is opened with Open.... Files of the old Graph Widget can be opened too. Their splits are computed again, except for splits at a tag, which old files don't store; these neurons are shown unsplit.

Clone opens a second Graph Widget 2 with the same graph. Deep links that include widget settings restore the graph as well.

Layouts made in other tools

Layouts can be made in other tools, e.g. Gephi, and opened again in CATMAID:

  1. Export the graph as GML in the Export tab. The default option (linearize IDs) is fine.
  2. Open the GML file in Gephi and make a layout.
  3. Export the graph in Gephi as GraphML file: File > Export > Graph file, file type "GraphML".
  4. Click Open... in the Main tab and select the GraphML file. The default import options work for Gephi.

Only whole neurons are matched again, through the unit_id field of the GML export. Parts of split neurons and groups are skipped.

Keyboard shortcuts

  • Delete: remove the selected nodes, after a confirmation.
  • J: group the selected nodes.
  • Hold Shift: zoom in smaller steps with the mouse wheel.
